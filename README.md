#hate-speech-detection-research

MSc Computer Science - PROM06

##Project Overview
This repository contains the code, data analysis and 
documentation for a research project examining automated 
hate speech detection, algorithmic fairness and platform 
amplification dynamics on social media platforms.

##Research Questions
- RQ1: To what extent do engagement metrics correlate 
  with increased visibility of hate speech posts?
- RQ2: What temporal patterns emerge in hate speech 
  during major socio-political events?
- RQ3: How do transformer-based classifiers perform 
  across hate categories?
- RQ4: How do classifier disparities interact with 
  amplification dynamics?

##Models
- HateBERT (primary classifier)
- RoBERTa (secondary transformer)
- SVM with TF-IDF (baseline)

##Datasets
- HateXplain
- ETHOS
- Measuring Hate Speech corpus
